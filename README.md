# hammerspoon-smcpad

**SMC-PAD Pocket**（16パッドのMIDIパッドコントローラ）を macOS の「左手デバイス」にする
Hammerspoon 設定。パッドにアプリの切り替え・ウィンドウ配置・プレゼン操作を割り当てる。

## 構成

| パス | 内容 |
|------|------|
| `hammerspoon/init.lua` | 本体（Luaコード） |
| `install.sh` | シンボリックリンクを貼るスクリプト |

## セットアップ

リポジトリのフォルダで次を実行する。

```sh
./install.sh
```

`install.sh` は `~/.hammerspoon/init.lua` へのシンボリックリンクを作成する。
既存ファイルがある場合は `.bak` に退避してから貼り直す。
その後 Hammerspoon を起動する。

初回のみ、システム設定 → プライバシーとセキュリティ → アクセシビリティ →
Hammerspoon をオンにする。

## 割り当て

パッドの並びは MPC／ドラム式で、**ノート36が左下**・行ごとに上へ上がる。
手前（下段）ほど使用頻度の高い開発系、奥（上段）ほど画面全体に効く操作。

```
上段  [48 スライド←]     [49 スライド→]     [50 別モニターへ移動] [51 通知センター]    ← プレゼン/画面
3段目 [44 左半分]        [45 右半分]        [46 最大化]           [47 モニター内巡回]  ← ウィンドウ操作
2段目 [40 Slack]         [41 ブラウザ]      [42 Claude]           [43 メモ]            ← 連絡/情報
下段  [36 VSCode]        [37 PyCharm]       [38 cmux]             [39 Sourcetree]      ← 開発
```

### 各パッドの動作

- **アプリ（36〜43）**: 未起動なら起動、起動中なら前面へ。すでに前面なら、そのアプリの
  次のウィンドウへ切り替える（別デスクトップ・別モニターのウィンドウも含む）。
- **左半分/右半分/最大化（44〜46）**: 前面のウィンドウを、今の画面の左半分・右半分・全体に合わせる。
- **モニター内巡回（47）**: 前面アプリのウィンドウのうち、今のモニターにあるものを順に切り替える
  （そのモニターの別デスクトップのウィンドウも含む）。
- **スライド前/次（48/49）**: PowerPoint のスライドを前/次へ送る。PowerPoint が前面になくても効く。
- **別モニターへ移動（50）**: 前面のウィンドウを、大きさを変えずに次のモニターへ移す。
  マウスカーソルは動かさない。
- **通知センター（51）**: マウスカーソルがあるモニターで通知センターを開く。

## カスタマイズ

- **パッド**: `PAD_ACTION` のノート番号にアクションを書く。
- **アプリ**: 先頭の `APPS` を編集する。アプリは **bundle ID を優先、無ければアプリ名**で
  探す。bundle ID の調べ方:

  ```sh
  osascript -e 'id of app "Slack"'
  ```

  そのMacに入っていないアプリのパッドは、押しても何も起きない。
- **別のデバイスを使う**: `DEVICE_MATCH` をデバイス名（部分一致）に、`PAD_ACTION` の
  ノート番号を実機に合わせて書き換える。

設定変更後は Hammerspoon コンソールで `hs.reload()` を実行する。

### MIDIの実値を調べる

パッドのノート番号・デバイス名を知りたいときは、冒頭の `DEBUG = true` にして `hs.reload()` し、
パッドを押してコンソールの `[MIDI]` ログを見る。確認後は `DEBUG = false` に戻す。

参考: SMC-PAD Pocket は **ノート 36〜51 / MIDI ch9**。
